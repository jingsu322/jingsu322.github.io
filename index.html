Web intelligence & ingredient extraction pipeline

In production

The business needed supplier and product intelligence at web scale without a web-scale budget. I built a crawling and LLM-extraction pipeline that runs on a single cost-optimized instance: Crawl4AI collects pages, the OpenAI Batch API does extraction at a fraction of real-time pricing, and S3-backed checkpointing with stale-batch recovery means a failed run resumes instead of re-paying for work already done.

  • 25,733 domains processed
  • 375,733 products extracted
  • 222,035 ingredients deduplicated
  • ≈$90 total LLM cost

End-to-end AI model lifecycle automation on AWS

Hands-on build

A governed ML lifecycle rather than a training script: preprocessing, training, evaluation, conditional promotion, and endpoint deployment orchestrated across SageMaker, Step Functions, and Lambda. Drift detection triggers retraining, and champion/challenger evaluation gates decide whether a new model is allowed anywhere near production traffic.

SageMakerStep FunctionsLambdaS3CloudWatchIAM

Cloud-native AI inference platform on Amazon EKS

Hands-on build

A containerized serving architecture that keeps routing, API, and asynchronous inference in separate layers — Envoy in front, Flask APIs in the middle, Kubernetes Jobs doing the heavy work. Namespaces, RBAC and ServiceAccounts, ResourceQuota, and LoadBalancer services isolate workloads the way a real multi-tenant cluster has to.
